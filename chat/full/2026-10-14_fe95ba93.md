## Launch plan

**1. Installing on another PC**
- **One setup file.** `Setup CAD to Revit.bat` copies the app to `C:\CAD to Revit\` on the colleague's PC and adds a desktop shortcut.
- **Python comes with the app.** It gets its own private Python, with the four libraries at the exact versions that pass our tests: ezdxf 1.4.4, shapely 2.1.2, openpyxl 3.1.5, rhino3dm 8.35. Nobody installs Python, nothing needs the internet, and other Python installs on that PC can't interfere.
- **DWG converter.** The app needs one to read DWG files. The free ODA File Converter is preferred; otherwise ZWCAD or BricsCAD on that PC is used. Setup tells them in plain words if none is found. It also fixes the ZWCAD "Run as administrator" setting that silently broke your runs on 12 October.
- **Revit add-in.** It installs itself the first time "Create a Revit file" is used (Revit 2025 or later). The connection plug-in is only needed for "Build in the open model", so setup marks it as optional.
- **"Check my installation" button.** It checks each of the above. It then runs the built-in sample drawings end to end (import, analyse, export an IFC) and shows a green or red line for each item.

**2. User guide for colleagues**
- **Where it lives:** a Help page inside the app, plus the same guide as a printable PDF.
- **What it covers:** start a project, import drawings, tick the floors, read the Review (what red, yellow and grey mean), set the floor levels, make decisions, then export or build in Revit.
- **Common mistakes:**
  - two floors at the same height;
  - heights typed in metres instead of mm (the "Level 1 = 1" case);
  - building before pressing "Save and update";
  - a re-issued drawing whose title names another floor;
  - the floor heights mixed up with the separate founding level for footings;
  - floors in between not imported.
- **A small safety check in the app.** I'll move the floor-level check that already stops the IFC/Rhino export forward to the Export page, so it shows before anything is built, Revit included.

**3. What the app does not do yet**
A page in the guide and in the app lists these:
- stairs, projections and chajjas, retaining walls, the underground tank and raft panels;
- stub columns from the footing up to the first level;
- leader lines (arrows pointing at a mark), and AutoCAD table objects;
- drawings in feet and inches (they are stopped), and scanned or PDF drawings;
- shaped beams in Revit, which haven't been tried live yet.

It also explains the rules for using the output:
- Anything built red has a working size that someone must decide.
- Always compare the Review with the drawing before building.

**4. Test checklist and problem reports**
- **Checklist:** about 10 ticks a colleague can run on their own job. Examples: are the column count and slab count right on one bay? Are the floor levels in the right order? Are the red elements explained?
- **"Report a problem" button.** It makes one zip with the project settings, the decisions, the latest run's summary, logs and check files, and a screenshot note. Attaching the drawings is optional, because of size and confidentiality. They email or drop that zip to you, and I can replay it here.

**5. Freezing the launch version**
- **Version and backup:** version **1.0.0**, shown on the app's welcome screen. The backup is `backups\App_1.0.0_<date>.zip`, made only after every test and baseline passes.
- **Two copies:** your working copy stays separate from the release copy that colleagues get.
- **How updates reach other PCs:** you put a new release in one shared office folder. When the app starts it compares versions and shows "A new version is available". The colleague then runs Update, which never touches their projects.

## Decisions I've made
- Python comes with the app rather than being a separate install. It's the only way to get a true one-click, offline setup.
- The full 5-minute test run stays on your PC. Colleagues get the shorter install check.
- The test drawings and baselines from your training projects stay out of the release.
- The shared folder for updates is set when the release is built. Until you name an office share, you can pass the release zip around by hand.

Stilt A, ALCAZAR HB and items 12, 10, 5, 11 wait until after the launch. None of them blocks it.
