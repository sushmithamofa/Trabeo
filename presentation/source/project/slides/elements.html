Standard · section 05

How each element is drawn, so a script can trust it

Columns

One closed rectangle per column, at the scheduled size, once only

Walls

Lift walls and pardi walls on S-WALL, never on the column layer

Beams

One centreline per span, justification set to zero, parallel to the grid

Girders

Drawn at the scheduled width, not at a nominal 350 for all of them

Slabs

One closed outline per panel, edges landing on the beam centrelines

Sunk areas

A closed outline on its depth layer, not a hatch on its own

Openings

Openings, stairs and landings as closed outlines on their own layers

None of these rules asks for extra drafting. A closed rectangle is no slower to draw than an open one, and a centreline is no slower than an edge line. It is the same work, done once, in a form that reads.
