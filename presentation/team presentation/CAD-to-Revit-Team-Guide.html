What it is

The app reads the structural drawings and builds the model for you

You give it a job's DWG or DXF drawings. It finds the columns, beams, slabs and walls, reads their marks and sizes, and builds the model in Revit, IFC or Rhino. You check the result.

1

Reads any consultant's drawings

Plans, schedules, details and sections. Each value is matched to the mark it belongs to, whatever the layer names or label style.

2

Shows where every value came from

Click any beam, column or slab to see its size and the drawing it came from. Where the drawings disagree, or say nothing, the app marks it for you to decide.

3

Builds the model

Download a Revit file, an IFC file, a Rhino file, or a package for whoever builds the model. Your decisions go into it.

The one rule: the app never guesses. A size that is not clear in the drawings is shown for you to decide. It is never filled in quietly.

Step 1

Import CAD: upload the drawings

Add every structural drawing of the job: DWG or DXF, from any consultant.

  1. Press Add drawings... to pick files, or Add a whole folder...
  2. Wait for “Uploading 3 of 8 …” to finish. Each drawing then appears in the list.
  3. Added one by mistake? Press the × beside it.
  4. Press Continue to Analyse →

Add more than the plans

Schedules, beam and column details and sections are where many sizes are written. The more of the set you add, the fewer values you'll have to fill in yourself.

Only DWG and DXF files are taken. Anything else in a folder is skipped.

CAD to Revit · Team guide8
Step 2

Analyse: tell it the floors, then let it read

The app ticks the floors it finds in the drawing names. Check them, then analyse.

  1. Floors: tick every floor the building has. Use Ground up to to tick a range at once.
  2. Names: pick each floor's Revit name, or use Level 0, 1, 2 ... / Ground, First, Second ...
  3. Heights: type each level's height in mm from the drawings' ±0, or type one floor-to-floor height and press Fill heights.
  4. Press Analyse drawings.

While it works

A bar shows each stage: Preparing → Reading drawings → Linking and checking → Writing the review → Writing Revit files → Done. A full set takes a few minutes. Show details has the full log.

New consultant?

Tick “Let the app work out what unfamiliar layers hold”. You will check what it found in Review.

Step 3 · making decisions

Click an element, check its sources, decide

The panel on the right lists each value (width, depth, thickness, mark …) with every drawing it was read from.

  1. Click a beam, column or slab, or an item in the Issues list on the left.
  2. Press use beside the source you trust, or type the value in the set box and press Save typed values.
  3. Apply to: this element only, or every B12 on level 3. One decision fixes them all.
  4. Not a real element? Exclude from model. Changed your mind? Undo decisions here.
  5. When you're done, press Done - Export →

Saved as you go

Every decision is saved in your project immediately (“saved in the project automatically”). Closing the browser loses nothing. The next analysis of the same project keeps your decisions.

Sizes are in millimetres

Type numbers only, e.g. 600, not 600mm. The app refuses a size that isn't a number above 0.

Unfamiliar marks

mark prefix in Issues: the app read a consultant's own marks (e.g. SL1) from their schedules. Confirm with beam slab …, then press Analyse again. did you mean: a mark written two ways (S01 / S1). It is never matched by itself.

Step 4

Export: check, then download your model

Press Export to Revit. The Before you build panel then shows what goes to the model and what is still waiting for you.

  • Needs a decision: not built until you decide it in Review. You can also tick “Build these anyway at a working size”: they are built in red, with the reason in their Comments.
  • Not built by the app yet: model these by hand for now.
  • Floor levels: fill in any missing heights, then Save and update the Revit files.

The same model in the open BIM format. Revit: File › Open › IFC.

A layer for each level and type. Anything still undecided is red.

Revit files, review page and summary, for whoever builds the model.

Know what to expect

What goes into the model

Built by the app

  • Columns: position, size and rotation, floor by floor
  • Beams: straight and curved, at their marked sizes
  • Slabs: with cut-outs, thickness and sunk areas
  • Walls and lift cores
  • Levels at the heights you gave

Check, or do by hand

  • Anything on the Not built by the app yet list on the Export page
  • Anything left red or yellow in Review: not built, or built red if you chose so
  • Reinforcement: listed in the Excel workbook, never modelled
  • Always compare the model with the drawings before you issue it
Remember: the app speeds up modelling. It does not replace your check. If something looks wrong, it is usually something the drawing doesn't say clearly. Review will show you where.

Good habits

Tips for a smooth job

  • One project per job (or per building). Name it clearly.
  • Add the whole set, not just the plans. Schedules and details fill in the sizes.
  • Work through the Issues list top to bottom. It is quicker than hunting on the plan.
  • Decide by mark (every B12 on level 3) when the same answer fits them all.
  • New revision? Use Start a new drawing set in the same project. Your decisions carry over.
  • Press Analyse again after changing floors or adding drawings, then export again.
  • Use the Help button (top right) for a quick reminder of the four steps.
  • Sign out when you're done on a shared PC.

Need help?

Found something wrong, or stuck?

Write it in the team issues sheet, so every issue is in one place and nothing gets lost.

Open the CAD to Revit issues sheet
  1. Open the sheet with the green button above.
  2. Make your own tab: press + at the bottom left, then double-click the new tab and rename it to your name.
  3. Write one issue per row on your tab, with the details on the right.
  4. Add new issues to the same tab each time.

What to write in each row

Date
Project: its name, and the drawing or floor
Element: its mark, e.g. B47
The issue: what you see, and what you expected
Screenshot: of the Review plan or model, with the place circled
